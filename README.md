# airtop-ai
Airtop AI - A comprehensive AI-powered API platform providing intelligent automation, data processing, and advanced AI capabilities

## Official plugins

Official Airtop AI plugins are registered in
[`plugins/official/registry.json`](plugins/official/registry.json).

### Winston AI

Winston AI is the first official plugin in this repository. It creates a staged
1-year execution outline for coordinating Airtop AI's installed plugin
ecosystem and validates that every installed plugin is represented in the plan.

- Manifest: [`plugins/official/winston-ai/plugin.json`](plugins/official/winston-ai/plugin.json)
- Documentation: [`plugins/official/winston-ai/README.md`](plugins/official/winston-ai/README.md)
- Outline: [`docs/winston-ai-outline.md`](docs/winston-ai-outline.md)
