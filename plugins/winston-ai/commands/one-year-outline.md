name: one-year-outline
description: Generate a 1-year execution outline for a project, product, company, or initiative.
---

Create a focused 1-year execution outline for the user's goal.

Before writing the outline:

1. Identify the goal, current state, audience, constraints, and definition of success.
2. If context is missing, proceed with explicit assumptions unless the result would be misleading.
3. Use relevant local repository context, installed plugins, MCP tools, or documentation when the plan depends on a specific platform.

Output:

- Objective
- Assumptions
- Success metrics
- Quarter-by-quarter roadmap
- Risks and mitigations
- Decision gates
- Immediate next actions

Keep the plan concise, measurable, and execution-oriented.
